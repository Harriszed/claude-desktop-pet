# Claude Desktop Pet

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Claude Code users who want a playful, unobtrusive desktop companion while they work.

## Product Purpose

Show Claude Code activity through a pixel mascot, session information and local scenery. Let users install and configure the companion without a terminal.

## Operating Context

An Electron desktop app on Windows, macOS and Linux, connected to local Claude Code hooks. Preferences are occasional tasks opened from the tray.

## Brand Commitments

Preserve the existing warm colours and pixel artwork. The user confirmed this audience and style for the settings window.

## Capabilities and Constraints

Settings bring size, visibility, weather, sounds and startup together. Sounds are off by default. The requested work excludes a new drop shadow. Platform permissions and signing requirements must be explained accurately.
